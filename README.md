# RHI Linux

Unofficial Linux-focused fork of [RankFTW/RHI](https://github.com/RankFTW/RHI) for Steam, Proton, and Linux desktops.

RHI Linux automatically discovers Steam games and installs compatible ReShade, RenoDX, and OptiScaler files using official upstream sources.

## Project status

**Version 0.1.2 — Early Alpha**

This release is usable, but it is still an early public build. Visual issues, compatibility problems, incomplete game profiles, and installation bugs may remain.

OptiScaler has primarily been tested on AMD gpus. NVIDIA specific behavior has not been thoroughly tested by the maintainer.

RHI Linux is unofficial and is not affiliated with or supported by the original RHI, RenoDX, ReShade, or OptiScaler maintainers.

> [!WARNING]
> Use this application only with single-player games. ReShade, RenoDX, and OptiScaler use runtime injection and may trigger anti-cheat systems in online games.
>
> Always review the generated installation plan and keep backups of important game files.

## Quick start

### Run from source on Linux (based on your distro)

```sh
sudo pacman -S --needed git dotnet-sdk-8.0

git clone --branch linux --single-branch \
  https://github.com/winterofhell/rhi-linux.git

cd rhi-linux

dotnet run \
  --project src/RhiLinux.Gui/RhiLinux.Gui.csproj \
  -c Release
```

After installing a compatibility setup, copy the Steam launch option generated by RHI Linux into the selected game's launch options.

## Requirements

- Linux x86_64
- .NET 8 SDK
- Native or Flatpak Steam (flatpak version was not fully tested)
- A Steam Proton game
- AMD GPU for the supported OptiScaler workflow

Install the SDK with `pacman -S dotnet-sdk-8.0`. Avalonia requires the normal desktop libraries provided by an up-to-date Plasma or GNOME installation.

## Build and test

```sh
dotnet restore RhiLinux.sln
dotnet build RhiLinux.sln -c Release --no-restore
dotnet test RhiLinux.sln -c Release --no-build
```

## CLI

```sh
dotnet run --project src/RhiLinux.Cli -- scan
dotnet run --project src/RhiLinux.Cli -- games
dotnet run --project src/RhiLinux.Cli -- candidates --game 123456
dotnet run --project src/RhiLinux.Cli -- status --game 123456
dotnet run --project src/RhiLinux.Cli -- profile --game 123456
dotnet run --project src/RhiLinux.Cli -- proxy-diagnostics --game 123456
dotnet run --project src/RhiLinux.Cli -- artifacts --game 123456
dotnet run --project src/RhiLinux.Cli -- stack-status --game 123456
dotnet run --project src/RhiLinux.Cli -- diagnostics --game 123456 --offline
dotnet run --project src/RhiLinux.Cli -- diagnostics --game 123456 --download
dotnet run --project src/RhiLinux.Cli -- plan --game 123456 --recommended
dotnet run --project src/RhiLinux.Cli -- cache verify
dotnet run --project src/RhiLinux.Cli -- plan --game 123456 --component renodx --source /path/to/original.addon64
dotnet run --project src/RhiLinux.Cli -- install --game 123456 --component renodx --source /path/to/original.addon64 --apply --yes
dotnet run --project src/RhiLinux.Cli -- remove --game 123456 --component renodx
dotnet run --project src/RhiLinux.Cli -- launch-option --game 123456
```

Use `--steam-root <path>` to scan fixture data or a nonstandard Steam installation. Use `--json` for machine-readable output. `diagnostics` never applies a plan or writes game/application state; `--download` explicitly permits validated official artifacts to enter the shared cache. File-changing commands remain dry runs unless both `--apply` and `--yes` are supplied. `--allow-anti-cheat` is additionally required when anti-cheat markers are present.

Manual executable and deployment-directory overrides can be saved with `candidates --game <game> --exe <path> [--deployment-dir <path>]`. Paths must remain inside the game installation.

## Desktop application

```sh
dotnet run --project src/RhiLinux.Gui
```

The desktop application opens on a searchable game workspace with a resizable library sidebar. A summary card explains whether the selected game is supported, whether files are installed or need updates, and the safe next action. Supported profiles expose a primary **Install recommended setup** action that resolves, downloads, caches, and validates official files before opening a short confirmation plan. Technical profile, filename, hash, cache, and executable diagnostics are kept under Advanced details.

The application performs a non-blocking cached update check after startup and provides **Check for updates** on demand. It distinguishes online current state, available updates, offline cached state, and failed checks. Local component files are available only through **Advanced troubleshooting → Use local artifact**.

Every action opens a short **Ready to install**, **Ready to update**, **Ready to repair**, or **Ready to remove** confirmation. Technical operations are optional details. Confirmation runs the transaction, verifies the installed state, refreshes the selected game automatically, and reports rollback if a step fails. Settings show the shared download-cache size and provide verification and cleanup actions.

Use `--steam-root <path>` one or more times to limit the desktop scanner to fixture data or nonstandard Steam installations. Press `F5` to refresh, `Ctrl+L` to focus search, or `Ctrl+Shift+R` to review a restore plan for the selected game.

## Steam launch option

RHI Linux generates an option in this form for a `dxgi.dll` proxy:

```text
WINEDLLOVERRIDES="dxgi=n,b" %command%
```

The DLL name changes with the selected proxy. Copy the generated value into the game's Steam launch options.

## Components and downloads

- ReShade with full add-on support is the host for RenoDX.
- RenoDX addons retain their upstream `.addon64` or `.addon32` names.
- OptiScaler can coexist with a managed ReShade proxy through `ReShade64.dll`.
- OptiScaler is installed from the exact current stable bundle layout; only its main DLL is renamed to the selected compatibility filename.
- OptiPatcher is not downloaded or installed. A legacy file previously managed by RHI Linux can only be removed through ownership-checked migration.

Third-party binaries are never included in this repository or package. Runtime downloads accept HTTPS sources from official upstream hosts, stream to temporary files, verify a published SHA-256 digest when supplied, validate archives and PE binaries, then atomically enter the cache.

Reviewed AppID profiles and unambiguous mappings from validated official RenoDX/RHI metadata are automatic. Verified Unity and modern Unreal layouts can use architecture-matched official generic fallbacks; legacy Unreal, unknown engines, ambiguous layouts, native Linux games, and anti-cheat-marked games do not receive a guessed addon.

## Data locations

State follows the XDG base directory specification:

- configuration: `$XDG_CONFIG_HOME/rhi-linux` or `~/.config/rhi-linux`
- data: `$XDG_DATA_HOME/rhi-linux` or `~/.local/share/rhi-linux`
- cache: `$XDG_CACHE_HOME/rhi-linux` or `~/.cache/rhi-linux`

The shared cache uses content-addressed blobs under `blobs/sha256`, release metadata, parsed bundle manifests, temporary staging, and quarantine. Identical ReShade, RenoDX, and OptiScaler files are stored once regardless of game. The default cleanup limit is 5 GiB and can be changed in Settings. Each modified game receives `.rhi-linux/manifest.json` plus transaction-scoped backups; its blob references protect required cache files from pruning.
